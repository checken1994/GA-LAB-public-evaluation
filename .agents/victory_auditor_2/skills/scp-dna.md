# SCP DNA Reasoning Skill

## Core Methodology
Apply the 26 SCP DNA principles as operational rules when analyzing problems, debugging code, verifying claims, designing systems, or performing audits.
- Core Operating Loop:
  1. Hỏi Tại sao (DNA #1 + #18)
  2. Tìm bằng chứng (DNA #5, #14, #20)
  3. Phát hiện missing piece (DNA #19, #25)
  4. Thử nhỏ + quan sát thực tế (DNA #12, #17)
  5. Reality test (DNA #26)
  6. Audit & calibrate (DNA #8, #22, #23)
- Key Decision Rules:
  - Never treat multiple sources sharing same origin as independent (DNA #5).
  - Majority agreement is not proof; demand independent lineage/adversarial check (DNA #14).
  - PASS only means "no error found within current scope and current evidence" (DNA #22).
  - Reality has final authority (DNA #26).
