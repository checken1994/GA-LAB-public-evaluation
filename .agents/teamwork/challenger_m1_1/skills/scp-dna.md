Source: `d:\scp\.agents\skills\scp-dna\SKILL.md`

## Core Operating Loop
1. **Hỏi Tại sao** — Start from the problem, not the solution. Ask "Tại sao?" at least 3–5 times.
2. **Tìm bằng chứng** — Gather evidence from independent lineages.
3. **Phát hiện missing piece** — Explicitly name what is missing or unobservable.
4. **Thử nhỏ + quan sát thực tế** — Small, reversible actions with clear observation.
5. **Reality test** — Concrete check. Reality has final authority (DNA #26).
6. **Audit & calibrate** — Log decisions, acknowledge limits, leave open questions.

## Key Decision Rules
- PASS != TRUE (DNA #22). PASS only means no error found within scope.
- Reality > Model (DNA #26).
- Fail-Closed when lacking authority or evidence (DNA #8).
- Independent verification required; Consensus != Truth.
